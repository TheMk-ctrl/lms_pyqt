Проект: Менеджер зашифрованных заметок «CryptoNotes»

1. Назначение программы
Приложение предназначено для хранения личных текстовых заметок с возможностью их шифрования. Данные хранятся локально в базе данных SQLite. Каждый пользователь имеет отдельный аккаунт и видит только свои заметки.

2. Технологии

Язык: Python 3.14
GUI: PyQt6
БД: SQLite через QtSql (QSqlQueryModel, QSqlQuery)
Шифрование: собственная реализация (hashlib, base64 — стандартная библиотека Python)
Сборка: PyInstaller

3. Структура базы данных

Таблица users — пользователи:

id, name (уникальное имя), pass_hash (SHA-256 хэш пароля)

Таблица categories — категории заметок:

id, title (название категории)

Таблица notes — заметки:

id, user_id (внешний ключ → users), category_id (внешний ключ → categories), title (заголовок), content (текст, хранится в зашифрованном виде), cipher (использованный алгоритм), created_at (дата создания)

4. Окна и формы

Окно входа / регистрации (LoginWindow):

Две вкладки: «Вход» и «Регистрация»
Поля: имя пользователя, пароль (с маскировкой), повтор пароля
Кнопки: «Войти», «Зарегистрироваться»
Валидация: проверка заполненности полей, совпадения паролей, уникальности имени

Главное окно (MainWindow):

Панель инструментов (тулбар) с кнопками: Добавить, Изменить, Удалить, Демо шифрования, Экспорт в txt
Строка поиска по заголовку заметки (фильтрация в реальном времени)
Выпадающий список фильтрации по категории
Таблица заметок (QTableView): отображает заголовок, название категории, алгоритм шифрования, дату создания
Кнопки управления под таблицей: Добавить, Изменить, Удалить
Двойной клик по строке — открывает окно просмотра
Строка статуса: количество заметок и имя пользователя

Диалог создания / редактирования заметки (NoteDialog):

Поле заголовка
Выбор категории (QComboBox)
Текстовое поле для ввода заметки (QTextEdit)
Выбор алгоритма шифрования (QComboBox): Без шифрования, Шифр Цезаря, XOR, Base64
Поле XOR-ключа
Чекбокс «Показать расшифрованный текст»
Кнопки: Сохранить, Отмена
При сохранении текст автоматически шифруется выбранным алгоритмом

Диалог просмотра заметки (ViewNoteDialog):

Только чтение
Отображает: заголовок, категорию, алгоритм, дату
Автоматически расшифровывает текст при открытии
Для XOR: поле ввода ключа и кнопка «Расшифровать»

Окно демонстрации шифрования (CipherDemoWindow):

Поле ввода произвольного текста
Выбор алгоритма
Поле XOR-ключа
Результат шифрования и обратной расшифровки в реальном времени
Кнопка «Показать все алгоритмы сразу»

5. Алгоритмы шифрования

Без шифрования — текст хранится как есть
Шифр Цезаря — сдвиг каждой латинской буквы на 3 позиции
XOR — побайтовое XOR с ключом, результат кодируется в Base64 для хранения
Base64 — кодирование строки, скрывает текст от беглого взгляда

6. Работа с файлами

Экспорт всех заметок пользователя в файл .txt через стандартный диалог сохранения (QFileDialog)
Файл содержит: дату, заголовок, категорию, алгоритм и зашифрованное содержимое каждой заметки

7. Требования к сборке

Файл requirements.txt с зависимостью PyQt6
Сборка в единый .exe через PyInstaller: pyinstaller --onefile --windowed --name CryptoNotes main.py
