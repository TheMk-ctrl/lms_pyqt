# Пояснительная записка к проекту «CryptoNotes»

## 1. Общая информация

**Название:** Менеджер зашифрованных заметок CryptoNotes  
**Технология:** PyQt6, SQLite (через QtSql)  
**Язык:** Python 3.14+

---

## 2. Идея проекта

Приложение позволяет хранить личные заметки с возможностью их шифрования прямо в программе.
Перед сохранением пользователь может выбрать алгоритм шифрования: шифр Цезаря, XOR или Base64.
Это делает данные нечитаемыми для постороннего, кто откроет файл базы данных.

---

## 3. Функционал

- **Регистрация и вход** — у каждого пользователя своя учётная запись, пароль хранится в виде SHA-256 хэша.
- **Создание заметок** — заголовок, текст, категория, выбор шифра.
- **Редактирование** — двойной клик по записи открывает диалог.
- **Удаление** — с подтверждением через QMessageBox.
- **Поиск** — по заголовку (LIKE-запрос через setFilter).
- **Фильтр по категории** — через QComboBox.
- **Экспорт в .txt** — через QFileDialog.
- **Демо шифрования** — отдельное окно для наглядного сравнения алгоритмов.

---

## 4. Алгоритмы шифрования

| Алгоритм | Описание |
|:---------|:---------|
| Шифр Цезаря | Сдвиг каждой буквы на 3 позиции в алфавите |
| XOR | Побайтовое XOR с ключевой строкой, результат кодируется в Base64 |
| Base64 | Кодирование, скрывающее текст (не является шифрованием в строгом смысле) |
| Без шифрования | Текст хранится в открытом виде |

## 5. Структура проекта

```
crypto_notes/
├── main.py                  — точка входа
├── requirements.txt         — зависимости
├── core/
│   ├── database.py          — подключение к БД, создание таблиц
│   ├── auth.py              — регистрация и авторизация
│   └── cipher.py            — алгоритмы шифрования
└── ui/
    ├── login_window.py      — окно входа/регистрации
    ├── main_window.py       — главное окно со списком заметок
    ├── note_dialog.py       — диалог создания/редактирования
    └── cipher_demo_window.py — демонстрация алгоритмов
```

## 8. Сборка в .exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name CryptoNotes main.py
```

Готовый файл появится в папке `dist/`.
